# Домашний бюджет

Сервис для учёта семейных расходов. Член семьи добавляет и просматривает свои траты в Telegram обычными сообщениями. Глава семьи использует веб-панель для просмотра и редактирования всех записей.

## Возможности

- Telegram-бот понимает сообщения на естественном языке и с помощью OpenAI-compatible LLM извлекает действие, сумму, категорию, дату и комментарий.
- В боте доступны добавление, просмотр, исправление последней и удаление подходящей траты.
- Запросы Telegram-бота всегда ограничены Telegram ID автора сообщения.
- Веб-панель показывает записи всех членов семьи, фильтрует их и поддерживает CRUD.
- REST API предоставляет операции над расходами, список участников и проверку состояния.
- PostgreSQL хранит данные в Docker volume, поэтому перезапуск контейнеров не удаляет записи.

## Быстрый запуск

Нужны Docker Engine и Docker Compose plugin.

1. Скопируйте пример конфигурации и при необходимости измените параметры:

   ```sh
   cp .env.example .env
   ```

2. Чтобы включить Telegram-бота, заполните `TELEGRAM_BOT_TOKEN`, `LLM_API_KEY` и при необходимости `LLM_BASE_URL` и `LLM_MODEL` в `.env`. Для запуска только веб-панели эти значения можно оставить пустыми.

3. Соберите и запустите сервисы:

   ```sh
   docker compose up --build -d
   ```

4. Откройте [http://localhost:8080](http://localhost:8080).

Посмотреть журналы приложения:

```sh
docker compose logs -f app
```

Остановить контейнеры, сохранив данные:

```sh
docker compose down
```

Данные PostgreSQL находятся в именованном томе `postgres_data`. Не используйте `docker compose down -v`, если хотите сохранить записи.


## Сообщения боту

Бот работает через long polling и принимает текст в личном чате. Примеры:

| Сообщение | Действие |
|---|---|
| `кофе 350` | добавляет расход на еду с комментарием «кофе» за сегодня |
| `такси 1200 вчера` | добавляет расход на транспорт за вчера |
| `покажи траты за неделю` | показывает записи и сумму за последние семь дней |
| `сколько потратил на еду в этом месяце` | считает расходы на еду за календарный месяц |
| `последнее было не 350, а 450` | исправляет сумму последней траты пользователя |
| `удали такси` | удаляет последнюю подходящую трату пользователя |
| `удали категорию еда на сумму 500 за сегодня` | удаляет совпадающую запись пользователя за сегодня |

Допустимые категории: `еда`, `транспорт`, `жильё`, `развлечения`, `здоровье`, `покупки`, `другое`. Валюта интерфейса и ответов бота — рубли.

## Веб-панель

В панели доступны:

- просмотр расходов всех членов семьи;
- фильтры по Telegram ID, периоду и категории;
- сводная сумма и количество записей для выбранных фильтров;
- создание, редактирование и удаление расходов.

Для записи через форму укажите Telegram ID члена семьи. Список участников формируется по уже сохранённым тратам. Чтобы ID появился в списке, сначала добавьте расход этого участника через Telegram.

Веб-панель не требует авторизации и показывает все семейные расходы. Не публикуйте её в открытом интернете без добавления подходящей защиты доступа.

## REST API

Базовый адрес локально: `http://localhost:8080`.

### Список расходов

```http
GET /api/expenses?page=1&pageSize=20&userId=123&from=2026-10-01&to=2026-10-31&category=еда
```

Все фильтры необязательны. Даты должны иметь формат `YYYY-MM-DD`. Ответ содержит `data`, агрегат `summary` и метаданные `pagination`.

### Создание расхода

```http
POST /api/expenses
Content-Type: application/json

{
  "userId": 123,
  "amount": 350,
  "category": "еда",
  "spentAt": "2026-10-16",
  "comment": "кофе"
}
```

Если `spentAt` не передан, используется текущая дата сервера.

### Операции с одной записью

- `GET /api/expenses/{id}` — получить запись.
- `PATCH /api/expenses/{id}` — изменить переданные поля (`userId`, `amount`, `category`, `spentAt`, `comment`).
- `DELETE /api/expenses/{id}` — удалить запись.

### Остальные маршруты

- `GET /api/members` — Telegram ID участников, у которых есть записи.
- `GET /api/health` — проверка состояния приложения.

Ошибки возвращаются в общем виде: `{ "error": { "code": "...", "message": "..." } }`.

## Конфигурация

Параметры задаются через переменные окружения или файл `.env`:

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `POSTGRES_PASSWORD` | пароль PostgreSQL | `expenses-dev` |
| `APP_PORT` | порт веб-панели на хосте | `8080` |
| `TELEGRAM_BOT_TOKEN` | токен Telegram-бота; пустое значение выключает бота | пусто |
| `LLM_BASE_URL` | корневой URL OpenAI-compatible API | `https://api.openai.com/v1` |
| `LLM_API_KEY` | ключ API языковой модели | пусто |
| `LLM_MODEL` | название модели | `gpt-4o-mini` |
| `TIMEZONE` | часовой пояс для дат в сообщениях Telegram | `Europe/Ulyanovsk` |

## Разработка и тесты

Для локального запуска Go-сервера нужна доступная PostgreSQL и установленный Go версии 1.23 или новее. Обычный запуск тестов не требует Telegram, ключа LLM или внешней базы данных:

```sh
go test ./...
```

Проверить сборку:

```sh
go build -buildvcs=false ./...
```

- HTTP-тесты проверяют CRUD, фильтры, сводку и ошибки REST API на изолированном хранилище.
- Модульные тесты проверяют сценарии Telegram-бота, изоляцию расходов по владельцу, валидацию, разбор ответа LLM и извлечение комментария из сообщения.
- Интеграционный тест проверяет CRUD и SQL-фильтры PostgreSQL. Чтобы запустить его, задайте `TEST_DATABASE_URL` для отдельной тестовой базы; тест создаёт и удаляет в ней временную схему.
